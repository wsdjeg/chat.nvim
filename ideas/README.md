# Ideas

新功能的想法池。想法先写在这里,成熟后再实现。

## 约定

- 一个想法一个文件:`NNN-short-slug.md`(三位序号 + 短横线小写短语),序号递增
- 文件开头用状态标记,方便追踪:

  | 状态 | 含义 |
  |------|------|
  | `draft` | 刚冒出来的想法,细节没想清 |
  | `design` | 方案基本成型,待评审/排期 |
  | `accepted` | 已确认要做,等实现 |
  | `rejected` | 放弃了(注明原因) |
  | `shipped` | 已实现(链接到 PR / commit) |

- 想法被实现后,文件**不删**,状态改 `shipped` 并指向实现位置 —— 留档可追溯

## 想法文件写什么

- **动机**:解决什么问题,什么场景
- **方案**:核心机制、关键代码骨架(想法阶段就写伪码/骨架,逼自己想清楚)
- **设计决策**:为什么这样做,拒绝了哪些替代方案
- **风险/未决问题**:安全、性能、语义分歧点
- **测试要点**:落地时要覆盖的行为
